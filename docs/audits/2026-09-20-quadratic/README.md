# 第四轮：二次回归的数值稳定性

基线 `f488fa3`，分支 `stage6/integration`。用户要求继续处理其他功能，温升测试保持延后。本轮只修改数值核心及回归测试，不改 UI，不覆盖正式包，不合并 PR。

## 复现与根因

按 diagnosing-bugs 流程先补真实引擎断言：[修复前日志](before.log)。

1. `x=[99999999,100000000,100000001]`、`y=[1,0,1]`，期望 `a=1`，旧实现得到约 `-2.06e-17`。
2. 大偏移带噪数据通过频数输入、或展开为重复样本，旧实现预测分别约为 `1.2049` 和 `1.3697`；表示方式改变不应造成这种差别。
3. 同时加入小量、退化数据及多项式统一系数缩放检查；这些基础反例在修复前通过，未把它们误记成新缺陷。

旧二次回归累加原始 x 的一至四次方，再解正规方程；大偏移使矩阵数值失衡，求和顺序不同又放大差别。即使仅修复系数，直接用展开后的 `ax²+bx+c` 预测也会再次抵消，故求解与预测都需要稳定坐标。

## 架构与实现

- 新增独立的 `QuadraticRegression`，负责二次拟合的归一化、列主元 Householder QR、秩判断和预测。
- 先将 x 平移并缩放到有限小区间，y 减去参考值后缩放；权重使用 `sqrt(f/max(f))`。零频数行完全不参与拟合、选参考点和缩放。
- 不再构造包含 x⁴ 的正规方程。相对秩阈值拒绝无法可靠分辨的设计矩阵，不把退化输入伪装成成功拟合。
- `RegressionResult` 保留五参数构造器和 `type/a/b/c/r` 访问方法，以及按这些值比较的 equals/hashCode/toString；从 record 改为不可变类，内部保存不可变局部拟合模型。
- UI 系数仍对应原坐标的 `a*x²+b*x+c`。核心 `estimateY/estimateX` 使用内部局部模型，不重新解析或使用舍入后的显示系数。手工使用旧构造器创建的对象没有局部模型，仍按传入系数计算。
- 二次反解使用避免明显相消的求根形式；精确线性退化按线性处理；常函数反解区分无解与不定解。
- QR 仅三列、工作量与样本数线性相关；循环有协作取消检查。不增加线程、后台轮询或常驻服务。

没有声称任意双精度病态问题都能可靠求解。预测模型是近似拟合，接近极值处的反解、超出输入可分辨精度的数据、严重权重失衡、超范围系数仍有数值边界；秩不足或非有限数值明确拒绝。不可从有限位数的系数显示推导“任意外推都精确”。
