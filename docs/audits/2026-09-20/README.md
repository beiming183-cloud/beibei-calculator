## 空闲占用与发热结论

读取应用进程 `/proc/<pid>/stat` 的 utime+stime，时钟精度 100 ticks/s。可复现脚本：[Measure-IdleCpu.ps1](Measure-IdleCpu.ps1)，[原始测量](idle-cpu.log)。

| 状态 | 观察窗 | 应用进程 CPU ticks 增量 |
| --- | --- | --- |
| 前台函数表结果页静止 | 10.071 秒 | 0（61→61） |
| 退到模拟器桌面，稳定 2 秒后 | 10.083 秒 | 0（63→63） |

这两个短窗**未观测到持续 CPU 活动**，只能排除当时明显的应用空转；不是零耗电证明，也不测 GPU/屏幕功耗、手机电流或温度。已有协作取消和 2 秒/100 万次数值取值预算继续保留；2 秒不是强制 watchdog，仍不能保证任何输入都在精确 2 秒终止。
