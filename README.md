# 北北计算器

一个面向 Android 的独立科学计算器项目。

北北计算器希望把实体科学计算器的高效率输入方式，与手机上的触摸交互结合起来：按键即时输入、语义化公式编辑、自然数学显示、历史计算、复制粘贴和触觉反馈都围绕“算得快、看得清、改得方便”设计。

> 本项目为独立开发项目，不隶属于任何计算器厂商，也不包含第三方厂商固件、品牌素材或来源不明的计算器源码。

## 目前能做什么

- 科学表达式计算与运算优先级处理
- 分数、幂、根号、三角函数等自然数学输入
- 复数、方程、不等式、统计、函数表等计算能力
- 矩阵、向量、进制和单位换算等工具
- 语义化光标移动、拖动选区与结构化删除
- 手机式复制、粘贴与历史计算交互
- 自动补齐合理的右括号，同时保留非法表达式检查
- 大数结果使用自然科学计数形式显示
- 连续计算时保留并展开上一条计算过程，方便核查
- 长按连续输入、连续删除与触觉反馈

项目仍在持续开发中。部分高级功能已经具备计算引擎，但对应的完整交互界面仍在完善，因此“底层能够计算”不等于“最终界面已经完成”。

## 设计方向

北北计算器不是对某一台实体计算器做像素级复刻，而是以手机使用体验为优先重新组织交互。

目前主要关注：

- **输入效率**：减少不必要的菜单跳转，让常用运算尽量直接完成。
- **公式可读性**：分数、幂、根号和科学计数尽量使用自然数学形式展示。
- **可编辑性**：光标、选区、删除和粘贴尽量遵循手机文本编辑习惯，同时保持数学结构完整。
- **结果可核查**：连续计算时可以追溯上一条计算过程，而不是只看到抽象的 Ans。
- **触屏手感**：按键尺寸、留白、震动反馈和长按行为以真实手机操作为准持续调整。
- **稳定性**：计算核心与 Android 界面分离，并通过自动化回归测试减少交互修改造成的计算回归。

## 界面风格

当前界面采用：

- 暖白色机身
- 浅绿色显示区
- 深色主文字
- 深金色二级功能标注
- 面向触屏使用重新调整的控制区和方向键布局

HOME 页面使用应用卡片组织不同计算功能，整体保持克制、清晰，不追求对任何现有硬件外观的复刻。

## 项目结构

项目主要分为两部分：

- `core`：计算、表达式、状态机和回归测试，尽量保持与 Android 界面解耦。
- `app`：Android 触摸交互、绘制、剪贴板、震动反馈和应用界面。

这种结构让计算逻辑可以独立测试，也方便后续逐步重做界面而不破坏核心运算。

## 构建与测试

项目使用 Java 17、Gradle 和 Android SDK 构建。

每次主要修改都会通过 GitHub Actions 执行核心回归测试并生成 Android 调试 APK。Debug APK 只用于开发验证；面向长期安装和覆盖更新的版本使用独立、固定的 Release 签名链。

近期正式版本可以在仓库的 **Releases / 发行版** 页面下载。

### 计算资源与发热控制

普通计算的执行键使用后台任务；AC、新输入和失焦会取消旧任务。数值计算共享每次 100 万次函数求值、2 秒的保护预算，超限明确报错，不悄悄降低精度。长按松手、失焦和页面销毁时会清理重复输入任务；界面不使用空闲连续刷新循环。

这些机制用于避免无效持续运算，**不等于已经验证手机不发热**。实际温度、耗电和触感仍需在手机上验证；具体见[修复与功耗验证边界](docs/audits/2026-09-19/FIXES.md)。

从 0.3.15 起，正式版本使用固定 Application ID `com.beibei.calculator` 和长期 Release 签名；正式发布流程会对版本、包名、签名以及关键 R8 构建异常做 fail-closed 校验，避免再次出现开发 Debug 签名变化导致的覆盖安装冲突或已知压缩异常进入正式发布。

## 独立开发说明

北北计算器的代码、测试、界面实现和项目名称均为独立开发。

数学公式、通用科学计算方法以及常见计算器交互属于功能参考范围；项目不使用第三方厂商的私有源码、固件、签名密钥或品牌素材。

如果你发现计算结果、交互逻辑或界面存在问题，欢迎通过 GitHub Issue 提交复现步骤。
